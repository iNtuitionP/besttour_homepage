## 추출된 사용 자산 (가이드에서 크롭 + 배경 투명화)

`public/brand/` 와 `mockups/assets/brand/` 양쪽에 동일 파일을 둔다.

| 파일 | 크기 | 용도 |
|---|---|---|
| `logo-bestour.png` | 1648×320 | **헤더 로고 (메인)** — 사장님 확정 |
| `logo-bestmobility.png` | 2110×265 | 푸터 관계사 줄 · 회사소개 |
| `symbol-mark.png` | 728×656 | 파비콘 · 앱 아이콘 · 워터마크 |

추출 방법: `brand-guide.png` 에서 좌표 크롭(bestour x91-498 y77-152, mobility x722-1419 y77-159,
심볼 x887-973 y454-531) 후 4~8배 확대, 근백색(min RGB ≥ 246)을 알파 0 으로, 205~246 구간은 선형 알파.

**심볼을 손으로 SVG 추적하지 않았다.** 원본 심볼이 87×78px 밖에 안 되어 벡터로 옮기면 형태를 지어내게 된다.
파비콘 32px 기준으로는 87px 원본이 2.7배라 충분하다. 벡터가 필요해지면 디자이너 원본을 받는다.

## 실측 브랜드 컬러 (2026-09-06, 가이드 스와치 픽셀 평균)

가이드에 적힌 팬톤 코드와 실제 스와치 렌더링 값이다. 팬톤→sRGB 변환표가 아니라
**가이드 파일에서 직접 측정한 값**이므로 이쪽이 기준이다.

| 역할 | 가이드 표기 | 실측 HEX | 흰 배경 대비 | 사용 가능 범위 |
|---|---|---|---|---|
| MAIN | PANTONE 2614 C | **`#6F1C7C`** | **9.67:1** | 본문 텍스트·버튼 배경 전부 가능 |
| SUB | PANTONE 461 C | **`#C8A359`** | 2.38:1 | ❌ 텍스트 불가. 장식·구분선·어두운 면 위 강조만 |
| POINT | PANTONE COOL GRAY 9 C | **`#7B7A7A`** | 4.28:1 | ❌ 본문 보조 텍스트 불가(AA 4.5:1 미달). 보더·아이콘 전용 |

**POINT 컬러 함정**: 4.28:1 은 WCAG AA 본문 기준 4.5:1 에 미달한다. 푸터·메타 텍스트에 그대로 쓰면
접근성 위반이 된다. 보더/아이콘용 `--gray #7B7A7A` 와 본문 보조용 더 어두운 토큰을 **반드시 분리**한다.

**팬톤 코드 논쟁 종결**: 조사 에이전트가 "PANTONE 2614 C 는 존재하지 않는 코드"라고 주장했으나
pantone.com 이 인접 코드 전부에 301 을 반환해 근거가 재현되지 않았다(스펙 §13.10). 어느 쪽이든
가이드 스와치를 직접 측정한 위 값이 기준이므로 이 쟁점은 구현에 영향이 없다.

## 브랜드 가이드에서 읽어낸 값 (2026-09-06)

- MAIN COLOR : PANTONE 2614 C (보라)
- SUB COLOR : PANTONE 461 C (골드/탠)
- POINT COLOR : PANTONE COOL GRAY 9 C
- 심볼: 8엽 플라워 마크 (보라 + 골드)
- 로고 버전: 세로형 / 가로형 / 심볼마크 단독 / 컬러버전 / 모노버전
- 전용 서체: 기존 서체와 동일 계열의 이탤릭 볼드
- 키워드: 안전(Safety) · 연결(Connectivity) · 신뢰(Trust) · 전문성(Professionalism)
- 신규 브랜드 태그라인: "안전한 이동, 더 나은 연결 – 베스트모빌리티"

## 왜 벡터 원본이 필요한가

가이드 이미지에서 잘라낸 비트맵은 (1) 레티나 화면에서 흐려지고,
(2) 배경을 투명하게 뺄 수 없고, (3) 모노버전을 못 만든다.
로고를 만든 디자이너에게 **AI 또는 SVG 원본**을 요청하는 것이 최선이다.
받기 어려우면 가이드 이미지(고해상도 PNG)로 심볼을 SVG 재작도한다.

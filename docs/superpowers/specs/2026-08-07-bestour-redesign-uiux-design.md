# 베스트투어 홈페이지 리디자인 — UIUX 단계 디자인 스펙

- 날짜: 2026-08-07
- 상태: 사용자 섹션별 승인 완료
- 대상: http://www.bestour.co.kr/ (그누보드 기반, 전세버스 대절 알선업)
- 참조: https://www.twdream.co.kr/ (견적 위저드 UX 패턴)
- 프로세스: YC design-with-AI 파이프라인 (soul.md → 무드보드 → 원샷 N개 시안 → 비교 갤러리 → 선택 → 확장)

## 1. 목표

노후화된 베스트투어 홈페이지를 현대적으로 리디자인한다. 이번 단계의 산출물은 **구현이 아니라 클라이언트(사장님) 컨펌용 UIUX 시안**이다.

핵심 원칙:
- **견적이 최우선.** 방문자가 버스 대절 사이트에 오는 이유는 견적이다. 견적 기능을 홈 전면(히어로)에 배치한다. 연혁·인사말류는 전면에서 제외하되 삭제하지 않는다.
- **기존 기능/메뉴 100% 보존.** 삭제 없이 재배치만 한다.
- **보라색 아이덴티티 유지 + 모던화.** 실제 버스가 보라색("보라색버스"가 브랜드 자산). 촌스러운 보라 원색을 세련된 톤(딥퍼플/바이올렛 + 뉴트럴)으로 재해석한다.

## 2. 이번 단계 산출물

- 클릭 가능한 **고충실도 정적 HTML 시안** — 백엔드 없음, 브라우저에서 바로 열람
- 견적 위저드는 **더미 요금표로 실시간 가격 계산이 실제 동작**하는 프로토타입 (실제 요금표는 추후 사장님에게 받아 교체)
- 저장 위치: 저장소 `mockups/` 폴더
- 홈 화면 시안 6개 + 핀 기능 있는 비교 갤러리 페이지
- 선택안 확정 후: 견적 위저드 상세 + 서브페이지 확장

구현(그누보드 대체, 백엔드, 배포)은 시안 컨펌 후 별도 단계.

## 3. 견적 기능 정책 (사용자 확정)

- 위저드에서 **예상 가격을 실시간으로 표시**한다 (더미 요금표 기반).
- 사용자는 **예약을 걸 수 있다**. 온라인 결제는 하지 않는다.
- **예약 확정은 사장님이** 한다. 확정된 예약에 대해서만 결제가 진행된다 (오프라인/추후).
- 완료 화면 문구: "사장님 확정 후 연락드리며, 확정된 예약만 결제 진행됩니다."

## 5. 홈 화면 구성 (순서대로)

1. 히어로 — "몇 번의 클릭으로 바로 견적" 카피 + 차량 카드 5종 (클릭 시 위저드 진입)
2. 실시간 견적/예약 현황 (기존 데이터 형식: `한** 45인승 관광버스 → 2026-08-06`)
3. 이용 방법 4단계: 견적 신청 → 사장님 확정 → 알림/연락 → 결제
4. 베스트투어 강점 그리드 (차량 옵션: DVD·노래방·정수기·냉장고 등 기존 콘텐츠 활용)
5. 갤러리 프리뷰
6. 공지사항
7. 푸터 (회사 정보 전체)
8. 플로팅: 전화 걸기 버튼

## 6. 견적 위저드 플로우 (7단계)

기존 견적요청 폼의 **모든 필드**를 수용한다:

1. **차량 선택** — 45인승 관광버스 / 35인승 관광버스 / 28인승 우등리무진 / 25인승 관광버스 / 16인승 관광버스 (카드 UI)
2. **여행 정보** — 여행구분(가족여행/관혼상제/워크샵/친목회/종교단체/공항픽업/대학MT/현장학습/외국인의전.관광/기타), 출발지/도착지(서울~제주 16개 시도), 경유지(선택), 운행구분(왕복/편도/편도·편도)
3. **날짜·시간** — 출발일시, 상행일시 (캘린더 + 시간 선택)
4. **대수·인원** — 차량 대수, 예상 인원
5. **예상 가격 실시간 표시** — 더미 요금표 기반 계산 결과
6. **연락처 + 추가 옵션** — 성명, 핸드폰, (전화번호/팩스/이메일 선택), 견적확인방법(핸드폰/전화/팩스/이메일), 계산방법(현금/카드/세금계산서발행), 주차료 포함 여부, VAT 10% 포함 여부, 남기고 싶은 말씀, 답변메일받기 → CTA "예약 걸기"
7. **완료 화면** — 접수 확인 + 사장님 확정/결제 안내

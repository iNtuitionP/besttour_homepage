## 1. 목표

노후화된 베스트투어 홈페이지를 현대적으로 리디자인한다. 이번 단계의 산출물은 **구현이 아니라 클라이언트(사장님) 컨펌용 UIUX 시안**이다.

핵심 원칙:
- **견적이 최우선.** 방문자가 버스 대절 사이트에 오는 이유는 견적이다. 견적 기능을 홈 전면(히어로)에 배치한다. 연혁·인사말류는 전면에서 제외하되 삭제하지 않는다.
- **기존 기능/메뉴 100% 보존.** 삭제 없이 재배치만 한다.
- **보라색 아이덴티티 유지 + 모던화.** 실제 버스가 보라색("보라색버스"가 브랜드 자산). 촌스러운 보라 원색을 세련된 톤(딥퍼플/바이올렛 + 뉴트럴)으로 재해석한다.

## 2. 이번 단계 산출물

- 클릭 가능한 **고충실도 정적 HTML 시안** — 백엔드 없음, 브라우저에서 바로 열람
- 견적 위저드는 **더미 요금표로 실시간 가격 계산이 실제 동작**하는 프로토타입 (실제 요금표는 추후 사장님에게 받아 교체)
- 저장 위치: 저장소 `mockups/` 폴더
- 홈 화면 시안 6개 + 핀 기능 있는 비교 갤러리 페이지
- 선택안 확정 후: 견적 위저드 상세 + 서브페이지 확장

구현(그누보드 대체, 백엔드, 배포)은 시안 컨펌 후 별도 단계.

## 3. 견적 기능 정책 (사용자 확정)

- 위저드에서 **예상 가격을 실시간으로 표시**한다 (더미 요금표 기반).
- 사용자는 **예약을 걸 수 있다**. 온라인 결제는 하지 않는다.
- **예약 확정은 사장님이** 한다. 확정된 예약에 대해서만 결제가 진행된다 (오프라인/추후).
- 완료 화면 문구: "사장님 확정 후 연락드리며, 확정된 예약만 결제 진행됩니다."

### 10.2 서비스 포지셔닝 — 공항 노선이 주력

- "송영"은 생소한 단어이므로 사용자 언어로 교체한다 (후보: "공항 픽업·샌딩", "공항 픽업", "공항 왕복·편도" — 사용자 확정 필요). 원문 병기 가능.
- **홈 히어로 = 5초 자동 로테이션 캐러셀**: 회사 철학·서비스 스토리 슬라이드. ①인천공항 픽업(가격 경쟁력 서사) ②"전국 어디서나 갑니다" ③외국인 투어 전문/신뢰 스토리 등. 견적 위젯은 시안 1처럼 히어로 우측 고정(캐러셀과 독립, 항상 노출).

### 10.3 견적·예약 플로우 확장

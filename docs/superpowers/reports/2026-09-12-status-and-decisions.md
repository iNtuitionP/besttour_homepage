## 3. 아키텍처 결정 (플랜 §2, ADR 10건 요약)

| ADR | 결정 | 왜 |
|---|---|---|
| 1 | 라우트 골격 `[locale]/(site)`·`(legal)`·`admin` 을 **첫 파일 전에** 확정 | 나중에 옮기면 발송된 문자의 `/guide` 링크가 죽음. admin이 공개 푸터(계좌) 상속 방지 |
| 2 | admin은 service role이 아니라 **`is_admin()` RLS** 위에 | service role은 RLS 우회 → 방어선이 함수 호출 하나뿐 |
| 3 | 읽기는 `lib/queries/`, **서버액션 금지** | `'use server'` export는 전부 공개 POST RPC |
| 4 | 서버액션 본체는 순수 함수, `'use server'`는 얇은 래퍼 | 테스트 가능성 |
| 5 | 법정 문구는 `lib/legal/disclosures.ts` **단일 원장**(함수 0) | 목업이 스킨을 갈아도 법정 문구 보존 |
| 6 | 동의는 **명시 체크박스**, `privacy_consent_at` default 없음 | default now() = 받은 적 없는 동의의 시각 = 허위 기록 |
| 7 | 통지는 **아웃박스**(pending → sent/failed, 부분 유니크) | after() 실패가 조용히 사라지는 경로 차단 |
| 8 | 목업 추종은 **커밋 해시 고정**, copy-parity 테스트 금지 | UIUX 세션 커밋이 내 CI를 깨뜨리지 않게 |
| 9 | 갤러리는 **브라우저 직업로드** | Server Action 1MB · Vercel 4.5MB 한도 |
| 10 | 환경 3분리 local/preview/prod | 프리뷰 테스트가 운영 DB에 실개인정보를 쓰지 않게 |
